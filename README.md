# luneo.no

Markedssiden for bookingsystemet Luneo. Statisk side.

- Norsk (standard): `index.html`, `personvern.html`, `kjopsvilkar.html`
- Engelsk: `en/index.html`, `en/privacy.html`, `en/terms.html`

Publiseres med Cloudflare Pages (ingen byggesteg, utdatamappe `/`).
Sidene genereres fra `body.nb.html`, `body.en.html` og `style.css` med `build.py` (ligger i kildemappen, ikke i repoet).
